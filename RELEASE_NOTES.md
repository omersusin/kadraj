# Kadraj v1.1.0

An editorial collage studio for screenshots and photos, now with a complete English interface and a deeper set of editing tools.

## Highlights

- **English throughout** — every screen, control, notice, and accessibility label.
- **Photo looks** — Warm, Cool, Mono, Fade, Vivid, and Film, each with adjustable strength.
- **Frame controls** — zoom, tilt, horizontal and vertical flips, duplicate, and reset per photo.
- **Captions** — serif or sans, adjustable size, top/middle/bottom placement, three alignments, auto/paper/accent tones, and an optional plate.
- **Undo and redo** — up to 40 steps, with continuous adjustments grouped into sensible edits.
- **Three new canvas ratios** — 3:4, 2:3, and 2:1.
- **Style tools** — a one-tap Surprise Me palette and composition randomizer, plus Reset Style.
- **Sharper exports** — zoom-aware source decoding for detailed crops.
- **Faster workflow** — photo duplication, reset adjustments, and a dedicated four-tab editor.

## Everything else

- Smart layout engine that reads image orientation and ratio variety.
- Auto, Grid, Flow, Hero, Strip, and Stack layouts.
- Eight palettes: Paper, Night, Clay, Sage, Mist, Rose, Ivory, and Olive.
- Spacing, margin, corner, mat, shadow, and grain controls.
- Auto, 2K, and 4K export in JPEG or PNG; saved to the `Kadraj` album in Photos.
- No internet permission, no account, no cloud. Everything runs on-device.

## Install

1. Download `kadraj-v1.1.0.apk`.
2. Allow app installs from this source in Android settings.
3. Open the APK and install.

Android 10 and up is required. The package is `com.omersusin.kadraj`; this and future releases are signed with the same release key.
