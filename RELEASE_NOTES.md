# Kadraj v1.3.0

A canvas-first rebuild with a calmer visual language, faster access to the tools that matter, and a safer project flow.

## Highlights

- **A new interface** — neutral charcoal, warm paper, and a single peach accent replace the heavy glass-and-aurora look.
- **More canvas, less chrome** — the editor now centers the composition. The control deck collapses to a slim tab bar and expands only when you need it.
- **No more clipped controls** — every panel scrolls, so tone, strength, caption, and frame options stay reachable on smaller screens.
- **Automatic scroll-into-view** — the selected template, ratio, palette, photo, and look scroll into the visible strip.
- **Visual template previews** — each layout chip shows the actual arrangement before you apply it.
- **Safer navigation** — a back button and system back open a confirmation sheet instead of silently clearing the project. The old “new collage” action is now guarded as well.
- **Cleaner home and help** — a compact, photo-led start screen and a concise Help & info sheet replace the marketing-style pages.
- **Faster-feeling motion** — springy sheet sizing, restrained fades, tactile chips, and a quieter stage halo.

## Everything else

- Smart layout engine that reads image orientation and ratio variety.
- Auto, Grid, Flow, Hero, Strip, and Stack layouts.
- Ten palettes: Paper, Night, Clay, Sage, Mist, Rose, Ivory, Olive, Sunset, and Lagoon.
- Per-photo looks with adjustable strength; light, contrast, color, and warmth; zoom, tilt, flips, duplicate, and reset.
- Captions with serif/sans, size, placement, alignment, tone, and plate controls.
- Spacing, margin, corner, mat, shadow, and grain controls, plus Surprise Me and Reset Style.
- Undo and redo up to 40 steps.
- Auto, 2K, and 4K export in JPEG or PNG; saved to the `Kadraj` album in Photos.
- No internet permission, no account, no cloud. Everything runs on-device.

## Install

1. Download `kadraj-v1.3.0.apk`.
2. Allow app installs from this source in Android settings.
3. Open the APK and install.

Android 10 and up is required. The package is `com.omersusin.kadraj`; this and future releases are signed with the same release key.
