# Kadraj

Ekran görüntüleri ve fotoğraflar için akıllı, editoryal kolaj stüdyosu.

Kadraj görsellerin oranını okur; telefon ekran görüntülerini, masaüstü
ekran görüntülerini ve karışık seçkileri ayrı ayrı anlar. Düzeni, boşluğu ve
kadrajı buna göre kurar. Her şey cihazda kalır.
